# 🐺 AI 狼人杀 · 全自动模拟对局（v2）

一个只用 **Python 标准库** 写的桌面版 AI 狼人杀：**N 名 AI 玩家（6~12 人）+ 1 名 AI 上帝**。
配置好接口后点一下「开始对局」，剩下的刀人、验人、用药、守护、开枪、自爆、发言、投票、宣判
全部由 AI 自动完成。

* **两种模式**：经典模式（11 人固定阵容随机发牌）／自定义模式（人数 6~12 自选 + 每个席位身份自选）。
* **9 项游戏设置**：自爆 / 遗言 / 奶穿 / 胜负规则 / 是否报身份死因 / 女巫刀口情报 /
  女巫双药 / 警长 / 上下文条数。**默认全部关闭，仅「遗言」默认开启**。
* **对话区三层显示**：公开内容=黑色正体；狼队频道=红色（只有狼阵营与观众可见）；
  上帝视角与私密信息=灰色斜体。**好人 AI 的提示词里永远不会出现狼队频道和上帝视角内容。**
* **发言气泡**：每条发言是一个独立浅色卡片，头部为 `6号 ｜ deepseek-chat  [发言]  预言家`。
* **开局锁死**：对局开始后所有设置入口（模式、身份、API、游戏设置）自动禁用，结束后解锁。
* **token 面板**：实时显示总消耗、输入/输出、调用次数、失败次数，以及每个席位单独消耗。
  （**不估算金额** —— 各家单价差异太大，按你的服务商单价自己乘即可。）

## 二、模型选择（重要）

程序**不固定任何模型**：每个席位的模型名由你在【⚙ API】里填，`ai_config.json` 里保存。
请求协议是 OpenAI 兼容的 `/chat/completions`，所以任何兼容接口都能用。

**DeepSeek 官方当前情况**（据官方发布说明）：

| 模型 ID | 说明 |
| --- | --- |
| **`deepseek-flash`** | 当前主力（V4.1-Flash，552B MoE，原生多模态），官方称多项测试超过 V4-Pro |
| `deepseek-v4-pro` | V4-Pro 正在退场；2026-09-14 起全部路由到 V4.1-Flash，按 V4.1 计费 |
| `deepseek-v4-flash` | V4-Flash 已退役，此名临时路由到 V4.1-Flash |
| `deepseek-chat` / `deepseek-reasoner` | 旧别名，**2026-07-24 之后停用**，现在会路由到 V4.1-Flash |

**思考模式**（不是靠换模型名，而是靠参数）：

* 在【⚙ API】里勾选 **「思考模式」**，程序会给该席位发送
  `reasoning_effort: "high"` + `thinking: {"type": "enabled"}`。
* **不勾选时会显式发送 `thinking: {"type": "disabled"}`** —— 这一点很重要：
  实测 V4.1-Flash 会**默认带思考**，把推理过程当正文返回（英文独白被当成台词），
  显式关闭后行为才稳定。
* 思考模式推理更强，但**更慢、更贵**（输出 token 明显膨胀），并且会**忽略温度**。
* 建议：只给狼人 / 预言家这类需要推理的席位开，其余保持关闭。
* 勾选后会显示在 API 表格的「阵营 / 状态」列（`🧠思考`）。
* 已开启思考模式时，程序会把 `reasoning_tokens` 一并计入消耗统计，不低估账单。
* 注意：其他服务商若不认这两个参数可能报错，那就把该席位的
  `"disable_thinking"` 设为 `false`（在 `ai_config.json` 里直接改）。

**双保险：台词清洗。** 即使模型把推理混进正文，引擎也会**逐句过滤**——
只保留中文台词句，丢掉英文思考 / 元叙述；中文台词不足时改用该情境的兜底台词，
并用灰色斜体记一条"该席位这次输出的是思考过程"，方便你排查是哪个席位不听话。

## 三、五步开始对局

1. **选模式**：工具栏左侧【经典】/【自定义】。
2. **（自定义）点【🎭 身份】**：先用 Spinbox 选人数（6~12），再逐行给每个席位选身份；
   界面实时校验（非法标红）并给出阵容平衡提示。三个快捷按钮：
   * **🎲 随机分配当前身份** —— 把你当前选好的身份在各位玩家之间随机打乱（组合不变、只换位置）；
   * **一键填默认牌组** —— 填入一套常用阵容；
   * **其余全填平民** —— 作为起点。
3. **点【⚙ API】**：给席位填 API 地址、模型、Key。
   * 表格固定显示**全部 12 个玩家席位 + 上帝行**，不会再出现"找不到 11 号"。
   * 支持服务商预设、【复制到全部席位】、【只填充未配置的席位】、【🔌 测试连通性】。
   * **同一个模型可以重复占多个席位**。
4. **点【🛠 游戏设置】**：按需要打开 9 项开关（见下表）。
5. **点【▶ 开始对局】**。之后可【⏸ 暂停/继续】【■ 停止】，用「节奏」滑杆调速。

> 点击右侧某个席位行，可以只改那一个 AI 的接口。

## 四、游戏设置（10 项）

**默认值：除「死亡时公开身份与死因」外，其余全部默认开启。**

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 允许普通狼人白天自爆 | **开** | 关闭后只有狼王 / 白狼王能自爆 |
| 启用遗言机制 | **开** | 第一晚出局者（除毒杀）有遗言；第二晚起夜间出局无遗言；白天出局（除自爆）都有 |
| 启用奶穿（同守同救死亡） | **开** | 守卫守护 + 解药同时作用于同一人 → 该玩家依然出局 |
| 死亡时公开身份与死因 | 关 | 唯一默认关闭项。关闭时公开播报只说「X号 出局」 |
| 女巫每晚都知道被刀的人 | **开** | 关闭后只有第一晚告知刀口 |
| 女巫同一晚可用两瓶药 | **开** | 关闭后解药与毒药不能同一晚同时使用 |
| 启用警长机制 | **开** | 第一个白天进行警长竞选；警长票 1.5 倍并决定发言顺序 |
| **投票允许弃票** | **开** | 放逐投票与警长投票都能弃票（见下） |
| 狼人胜利规则 | 屠边 | 屠边=平民或神职全灭即胜；屠城=好人全灭才胜 |
| 上下文条数 | 60 | 20 / 30 / 60，直接影响 token 消耗与 AI"记忆力" |

### 弃票规则（开启后）

* 放逐投票、平票重投、警长竞选投票**都**支持弃票；AI 把 `vote` 填 `null` 即为弃票。
* 弃票**不计入任何候选人**，也不等于投给自己。
* 平票判定只看"候选人之间最高票是否并列"；**弃票数不与票数比较**。
  若最高票唯一（哪怕只有 1 票、其余人弃票），该玩家出局。
* 若某候选人得票并列 → 进入重投，且**平票者不能再被投**（避免"复活参选"），
  他们的票不再计入。
* 计票横幅会显示弃票名单；**同时被别人投票的人不会出现在弃票名单里**
  （例如 3 号自己弃票、但 2 号投了 3 号，则 3 号显示为"2 票"，不计入弃票）。

## 五、身份与技能

| 身份 | 阵营 | 技能 |
| --- | --- | --- |
| **狼人** | 狼 | 每晚与队友共同刀人；白天任意时刻可自爆（受设置控制） |
| **狼王** | 狼 | 每晚刀人；被刀杀 / 被放逐时开枪带走一人；白天可自爆（**自爆不开枪**） |
| **白狼王** | 狼 | 每晚刀人；白天自爆时**带走任意一名玩家**并直接进黑夜 |
| **平民** | 好人 | 无技能 |
| **预言家** | 好人 | 每晚查验一人是狼/好人，**结论只有自己知道**，白天要靠自己发言说出来 |
| **女巫** | 好人 | 一瓶解药（救回当晚被刀者）+ 一瓶毒药（毒死一人）；默认两药不能同晚用 |
| **猎人** | 好人 | 被刀杀 / 被放逐时开枪带走一人；**被毒杀不能开枪** |
| **守卫** | 好人 | 每晚护一人免于被狼刀；**不能连续两晚守同一人，也不能连续两晚空守** |
| **白痴** | 好人 | 被投票放逐时翻牌不死，但**失去投票权**（仍可发言） |

### 关键机制

* **自爆**：狼人在**任意玩家发言结束后**可自爆 → 自爆者出局，当天剩余发言与投票全部取消，
  直接进入黑夜。夜晚不能自爆。被白狼王带走的人若是猎人/狼王，可以开枪。
  * 实现细节：**每只狼每天只判定一次自爆**（在它自己发言之前判定；他人发言结束后只会问
    还没表态过的狼）。这样既省调用，也避免同一只狼被反复追问、把已经出局的队友当成还在场。
  * 自爆判定的提示词里会写明：自爆即出局、当天流程取消、**若自爆后场上再无狼则好人立即获胜**、
    以及当前存活的狼队友名单。
* **遗言顺序**：夜间出局者的遗言在**天亮后最先**说；白天出局者的遗言在**整轮最后按死亡顺序**说；
  猎人/狼王的遗言排在自己开枪**之前**（若他已经开过枪并说过话，就不再重复问遗言，
  避免同一段话被说两遍）；自爆与毒杀无遗言。
* **开枪连锁**：猎人 / 狼王被刀、被放逐、被枪杀、被白狼王带走时都会开枪（毒杀除外）；
  被他的枪打死的人若也是猎人 / 狼王，会继续开枪——但**每人只开一枪**，不会无限连锁。
* **信息隔离（很重要）**：喂给 AI 的"公开发言实录"里**只有玩家当众说过的话**和当众公布的事实
  （死讯、计票结果、警长当选、谁自爆）。女巫用药、守卫守人、验人思路、狼队密谈这些
  只出现在界面上给**你（观众）**看，**永远不会**进入其他 AI 的提示词——所以玩家只能靠
  "别人说出口的宣称 + 投票行为"来推理。这正是"4 号不能凭空知道 7 号没救他"的保证。
* **胜负**：狼人全灭 → 好人胜；平民或神职全灭（屠边）／好人全灭（屠城）→ 狼人胜；
  狼人数量超过好人 → 狼人胜。若牌组里没有平民（或没有神职），对应的屠边条件自动失效。

### 一局流程

```
第 N 夜：狼人刀人 → 守卫守护 → 预言家验人 → 女巫用药 → 天亮公布死讯
第 N 天：夜间死者遗言（仅第一晚）→ 警长竞选（仅第一个白天，若开启）
        → 依次发言（每名玩家发言结束后判定是否自爆）→ 投票放逐
        → 白天出局者遗言（最后）→ 进入下一夜
```

## 六、对话区怎么读

| 样式 | 含义 |
| --- | --- |
| **黑色正体**（白色气泡） | 所有人都能看到的内容：发言、上帝播报、死讯、投票 |
| **红色正体**（浅红气泡 + `[狼队频道]`） | 只有狼人阵营和**观众（你）**能看到；好人 AI 的提示词里没有这段 |
| **灰色斜体**（浅灰底） | 只有上帝/观众能看到：狼队刀口、守卫选择、结算判定、验人结果、私语 |
| 居中浅色横条 | 阶段横幅（`第2夜 · 守卫守护`），不再是刺眼的纯色大块 |
| `🗳 X 投票 → Y：理由` | 逐票明细 |

## 七、Token 消耗参考

每局实际消耗与「人数 × 轮次 × 上下文条数」强相关。实测（本地假模型跑完整对局，只有模型是假的）：

| 场景 | 调用次数 | 总 token |
| --- | --- | --- |
| 6 人局，3 轮结束 | 约 60~90 | 约 3~5 万 |
| 8 人局，2~3 轮结束 | 约 80~120 | 约 4~8 万 |
| 10~11 人局，3~5 轮结束 | 约 120~200 | 约 8~16 万 |
| 打满 7~8 轮的长局 | 约 250~350 | 约 25~45 万 |

省 token 的办法：把「上下文条数」调到 20、`max_tokens` 调到 300、发言要求写短、
少配神职（神职多会拖长对局）、用便宜模型。

## 九、常见问题

**Q：某个席位报错 401 / 余额不足？**
A：只有那个席位会中断并显示红色错误行，它这一次走本地兜底（仍会发言投票），对局不会崩溃。

**Q：想让同一个模型扮演所有席位？**
A：可以。在【⚙ API】里选中 1 号席位填好，点【复制到全部席位】。每个席位仍是独立人格与
独立信息范围（狼人只看到狼队频道，预言家只知道自己的查验结果）。

**Q：为什么好人现在很难赢？**
A：因为预言家的查验结果**只有他自己知道**（标准规则），好人失去"上帝给答案"的锚点。
想让好人好过一点，可以在游戏设置里打开「死亡时公开身份与死因」。

**Q：想改规则怎么办？**
A：规则文案在 `game_engine.py` 的 `ROLE_BRIEF` / `_system_prompt`，
流程在 `night_phase` / `day_phase` / `explode_check` / `vote_round` / `check_win`，
界面无需改动（所有内容都通过 `emit(kind, payload)` 事件渲染）。
